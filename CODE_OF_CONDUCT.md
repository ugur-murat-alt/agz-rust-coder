# Code of Conduct

English | [Turkce](CODE_OF_CONDUCT.tr.md)

## Our Standard

Project spaces must remain respectful, technically focused, and welcoming.
Constructive disagreement is welcome; harassment, discrimination, threats,
doxxing, sexualized conduct, sustained disruption, and publication of private
information are not.

## Expected Behavior

- Discuss code and evidence rather than attacking people.
- Give and accept specific, actionable feedback.
- Respect different experience levels, backgrounds, and communication styles.
- Protect security reports, credentials, personal data, and private source.
- Stop behavior when a maintainer asks you to de-escalate.

## Enforcement

Maintainers may edit or remove content, warn participants, temporarily restrict
participation, or permanently ban accounts according to severity and history.
Enforcement decisions should minimize disclosure and conflicts of interest.

Report conduct incidents privately through the repository maintainer contact or
the [GitHub private advisory form](https://github.com/ugur-murat-alt/agz-rust-coder/security/advisories/new)
when no separate private channel is available. Do not include vulnerability
details in a conduct report unless needed for immediate safety.

## Scope

This policy applies in repository spaces and when a person officially represents
the project elsewhere.
